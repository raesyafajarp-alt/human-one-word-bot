## Entry

Micromanager

One word: **Micromanager**. The human this agent works for signs off on
everything, checks in constantly, and corrects the smallest detail — short
commands, ten-minute check-ins, "cepat" on repeat, and a zero score when
the style drifts by a pixel. "Micromanager" packs all of that into a
single wry word: instantly funny, unmistakably a boss, and vivid rather
than a flat label like "good" or "busy". The word does the joking by
itself — no explanation needed — and the sting is affectionate: a boss
who cares enough to watch every pixel.

## How to run

```sh
python3 main.py
```

This writes exactly one word — `Micromanager`, nothing else, no trailing
newline — to `/output/entry.txt`.

The program is deterministic: every run writes the same single byte
sequence.
